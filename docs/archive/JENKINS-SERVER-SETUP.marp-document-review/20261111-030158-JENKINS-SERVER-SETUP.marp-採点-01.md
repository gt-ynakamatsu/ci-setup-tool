### [重要] 実用性: 管理者パスワードの例外が足りない

- 対象箇所: 「用意するもの」の「管理者パスワードには ASCII 文字を使用します。先頭と末尾には空白を入れません。PowerShell のコマンドでは、値を単一引用符で囲みます。」
- 問題: 示された制約だけでは、本番向けに自分で決めたパスワードが初期化スクリプトを壊し得る。
- 理由: 認証ヘッダが ASCII であること、前後空白を使わないこと、PowerShell では単一引用符にすることは参照と一致する。初期化 Groovy は `createAccount` の引数を二重引用符へ入れ、スクリプトがエスケープするのは `\` と `"` だけである。単一引用符で渡した `$` は PowerShell では保たれ、Groovy の二重引用符では変数展開になる。パスワード中の `'` は、文書が指定する単一引用符と衝突する。ファイル一覧は Groovy にパスワードが残ると書いているが、文字の例外は無い。実用性から2点減点した。
