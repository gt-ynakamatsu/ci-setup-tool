## 正確性

### パスワードの保存と再実行（重要、減点 2）

- 対象箇所: 「用意するもの」の「省略時は `C:\jenkins\cisetup-admin-password.txt` へ保存します。再実行時に同ファイルがあれば、その値を使います。」
- 問題: 再実行では、ファイルがあれば常にその値を使うように読める。
- 理由: スクリプトは `-AdminPassword` が空のときだけファイルを読む。実行例は `-AdminPassword` を付けるので、同じコマンドの再実行ではファイルではなく引数が使われる。ファイルへの書き込みは生成時に限らず、ファイルが無いときは指定したパスワードも保存される。

### ファイアウォールの完了表示（重要、減点 2）

- 対象箇所: 「ファイアウォール規則」の「規則の追加に失敗しても処理は続き、完了時に規則名が表示されます。」
- 理由: 追加または削除に失敗したとき、完了時は「ファイアウォール規則を処理できませんでした:」に続けて失敗した規則名が出る。成功時の完了表示に規則名はない。原文は「失敗した規則名」と書いていた。

### Git 導入失敗の対処（重要、減点 2）

- 対象箇所: 「主なエラーと対処」の「Git または .NET の導入エラー / 表示された取得物を削除して再実行」
