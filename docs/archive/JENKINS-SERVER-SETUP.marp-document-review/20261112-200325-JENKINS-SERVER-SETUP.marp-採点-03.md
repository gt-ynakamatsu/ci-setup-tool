### [重大] ログイン失敗から完了条件へ進めない

正確性 -5、論理性 -4、構成 -2、実用性 -3。重大はこの1件。

#### 正確性（-5）

- 対象箇所: 「主なエラーと対処（ログイン・プラグイン）」の `Jenkins へのログインに失敗しました`。「Jenkins の設定を作り直す場合」
- 問題: 参照スクリプトは、ログイン失敗時に「初回に指定したパスワードで入れない場合は、C:\jenkins を削除してから同じコマンドを再実行してください」と出して終了する。改稿案はこの文言を引用したうえで、削除と作り直しを実施しないと書いている。
- 理由: 引用自体はスクリプトの throw 文と一致する。手順の指示が参照資料の回復手順と逆である。原文の「Jenkins の設定を作り直す場合」は、Jenkins とエージェントを終了してから `C:\jenkins` を削除し、消えるものと残るものを書いていた。

#### 論理性（-4）

- 対象箇所: 同上、および「完了条件」
- 問題: 完了条件は、設定用 PC の CISetup で「Jenkins への接続に成功しました。」と表示されることである。ログインに失敗したとき、スクリプトが示す回復を禁止し、成功へ戻る別の手順がない。
- 理由: 失敗から完了条件へのつながりが切れる。実行者は、画面の案内と手順書の禁止のどちらに従うかが決まらない。

#### 構成（-2）

- 対象箇所: 「Jenkins の設定を作り直す場合」
- 問題: 見出しは作り直す場合の手順を示しているが、本文は実施しない、で終わっている。
- 理由: 見出しと本文が対応しない。トラブル時の節として、その例外のやり方が欠ける。

#### 実用性（-3）

- 対象箇所: 同上
- 問題: 次の行動が「初回に指定したパスワードを確認する」と「削除しない」までである。そのパスワードで入れない場合に、接続テストまで進む操作がない。
- 理由: この失敗はスクリプトが終了する例外であり、目的である接続テスト成功に必要な回復が手順にない。
