- 対象箇所: 「スクリプトの処理」の「JDK 21 を `C:\jdk21` へ展開し、マシン PATH の先頭へ追加する」
- 問題: 展開先は `C:\jdk21` で正しい。PATH に足すのはそのフォルダではなく、`java.exe` がある `bin` である。直前の .NET は `C:\dotnet` 自体を先頭へ足すため、同じ書き方だと JDK も `C:\jdk21` を足すように読める。
- 理由: 操作者が PATH を手で足す手順ではない。導入そのものを失敗させる記述ではない。
