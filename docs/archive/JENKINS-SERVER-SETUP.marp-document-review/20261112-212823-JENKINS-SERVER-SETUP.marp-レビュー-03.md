### [重大] スクリプトが初回実行前の条件で停止するように読める

- 対象箇所: 「対象」ページ最終段落「初回実行前だけは上記の条件で停止し、再実行では途中の作成物を再利用します」
- 問題: 列挙した条件があると初回だけスクリプトが停止するように読める。スクリプトに初回と再実行を区別する処理はなく、これらの条件で停止する処理もない。
- 理由: `C:\jdk21` に Java 21/25 がなければ削除して展開し直す（850〜853行）。`C:\dotnet` があればアクセス権を制限して .NET を導入する（811〜815行）。`C:\jenkins` はそのままアクセス権制限の対象（887〜891行）。`jenkins.war` を含む `java.exe` があれば起動せずそのまま使う（960〜963行）。MSI 版 Jenkins は停止ではなく、導入・PATH 変更・アクセス権変更のあと終了コード0で終わる（873〜881行）。停止を安全装置と考えた実行者が対象外のサーバーで実行すると、既存フォルダの削除や既存 Jenkins ホームのアクセス権変更が起き得る。
- 修正案: 判定するのは実行者であり、スクリプトは停止しないことを明記する。
