### [重要] 完了確認のログが、プラグイン結果の出る欄と特定できない

- 対象箇所: 「16. 完了を確認する」の1点目「CISetup の実行ログに必須プラグイン7個の ID があり」。対になる記述は「9. プラグイン7個を確認する」の「初期設定の実行ログ」。
- 問題: 同じログを、9では「初期設定の実行ログ」、16では「CISetup の実行ログ」と呼んでいる。画面上の見出しは、初期設定欄の「実行ログ」と、⑥の「ローカルビルド＆テストの実行ログ」の二つがある。
- 理由: プラグインの結果は `setup_server` のログとして初期設定欄の「実行ログ」へだけ入る。ローカルビルドの実行ログには ID は出ない。完了判断のときに別の欄を見ると、7個がそろっていても未完了に見える。
- 減点: 整合性 -2

### [重要] エージェントの Java は、11以上だと確認する手順になっていない

- 対象箇所: 「13. エージェント PC を準備する」の1と2。対比は「1. Jenkins サーバーへ JDK を入れる」のメジャー版確認。
- 問題: 導入は「Java 11 以上」なのに、確認は `java -version` で実行できることだけである。サーバー側は、環境スキャンが版を判定しないと書いたうえで、メジャー版が 21 または 25 であることを確認させている。
- 理由: 起動コマンドの注記と環境スキャンの案内は、エージェントを JRE 11 以上としている。スキャンは `java -version` に出力があれば検出済みにするだけで、8 でも検出済みになる。古い Java が PATH にある PC では、11 以上を入れたつもりでもエージェントがオンラインにならない。
- 減点: 実用性 -2

### [軽微] 環境スキャンの項目名が、実装の表示名と少し違う

- 対象箇所: 「13. エージェント PC を準備する」の「Git for Windows、.NET SDK、Java、Jenkins（この PC）の4項目」。
- 問題: 4項目であることと、Git for Windows、Jenkins（この PC）は一致する。残りは、実装の表示名が `.NET SDK 8.0` のような版付きと `Java (JRE/JDK)` である。
- 理由: スキャン結果の `name` と照合すると、.NET SDK と Java は略称になっている。行の取り違えまでは起きにくいが、名称としては実装と一致していない。
- 減点: 正確性 -1

### [軽微] API Token の生成で押すボタンが特定できない

- 対象箇所: 「5. API Token を発行する」の3「生成操作を押す」。
- 問題: 同じ手順の1は `Add new Token` まで画面の語で示している。3だけ「生成操作」で、押すボタンの名前がない。
- 理由: 発行直後の値をコピーする、という次の操作にはつながる。ただし、直前まで画面上の英語名でたどる手順の中では、押す対象が一つに定まらない。
- 減点: 明瞭性 -1

### [軽微] 操作名が行の途中で分かれている

- 対象箇所: 3枚目の「スクリプト手順」、6枚目の「ユーザー名」、9枚目の「Jenkins サーバーを初期設定」、10枚目の「起動コマンド」。

### [提案] .NET SDK が空欄のときの扱い

- 対象箇所: 「13. エージェント PC を準備する」の「CISetup の「.NET SDK」で指定した .NET SDK」。
- 問題: プロジェクトを開く前は、この欄が空のままのことがある。
- 理由: 空欄はスキャンも起動コマンドの注記も 8.0 として扱う。欄が空なら 8.0 を入れる、と一文あると、初回設定の時点で版が決まる。

### [提案] エージェントラベルの場所

- 対象箇所: 「初期設定ボタンを押し直すとき」の「ラベルを CISetup の「エージェントラベル」の値にする」。
- 問題: 項目名はあるが、どの欄かは書いていない。
- 理由: 入力欄は詳細設定の「CI ジョブの詳細」にある。既定は空欄で、空欄のとき Jenkinsfile は `agent any` になる、という10の説明とつながる。

### [提案] Jenkins 画面の項目名の併記

- 対象箇所: 「10. 組み込みノードの実行数を 0 にする」の「実行数」、「11. エージェント用 TCP ポートを設定する」の「固定値」。
- 問題: メニューは `Manage Jenkins → Nodes`、`Manage Jenkins → Security` と英語で、変える項目は日本語の説明だけである。
- 理由: 実装は実行数 1 のノードを作り、起動コマンドに TCP ポート番号は含めない。ポートを固定してからエージェントを起動する順序は合っている。画面が英語のときは、Number of executors と TCP port for inbound agents の Fixed を併記すると、探す語がそろう。
