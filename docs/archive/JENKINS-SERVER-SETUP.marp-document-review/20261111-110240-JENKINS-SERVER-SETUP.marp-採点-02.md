## 正確性 23/25

### [重要] プラグインが有効でないときの再起動が、起動中の Jenkins を止める手順になっていない

- 対象箇所: 「主なエラーと対処（JDK・Jenkins）」の `必要なプラグインが有効ではありません`
- 問題: 対処が「`start-jenkins.bat` で再起動し、別の管理者 PowerShell で同じコマンドを再実行」になっている。このエラーが出る時点で Jenkins は応答している。`start-jenkins.bat` は動いている Jenkins を止めず、同じポートで別の `java -jar` を起動する。再実行側は `jenkins.war` の `java.exe` が残っていれば新しいウィンドウを起動せず、そのプロセスを再利用する。
- 理由: `Setup-JenkinsServer.ps1` はプラグイン検査に失敗すると `必要なプラグインが有効ではありません` で止まる。再起動するのは導入結果が `RESTART required` のときだけで、その経路は検査の前に終わる。検査失敗後の再実行は、起動中の Jenkins を検出して再利用する。記載の2手順ではプロセスが置き換わらない。
