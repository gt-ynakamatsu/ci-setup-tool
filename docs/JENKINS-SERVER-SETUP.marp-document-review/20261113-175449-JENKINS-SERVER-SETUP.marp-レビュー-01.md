- 対象箇所: 10枚目「既存環境が見つかった場合」の「次のいずれかがある場合は、この手順を開始せず、既存環境の管理者へ確認してください。」

### [重要] 確認の後にサインアウトしたときの状態と、次の行動が書かれていない

- 対象箇所: 20枚目、27枚目、33枚目の「確認が終わるまでサインアウトしないでください」、28枚目「次は…CI ジョブを作成します」、61枚目「再起動後」
- 問題: セットアップ中の Jenkins とエージェントは、スクリプトが実行者のセッションで `Start-Process -WindowStyle Hidden` を使って起動します。起動タスクはサーバー起動時だけ動きます（`-AtStartup`、`StartWhenAvailable` なし）。そのため、確認の後にサインアウトすると、次にサーバーを起動するまで Jenkins が止まった状態になると考えられます。本文の書き方では、確認が済めばサインアウトしてよいと読めます。
- 理由: 完了と判断した直後に、次の作業（CI ジョブの作成）で接続できなくなるおそれがあります。完了条件を満たしたあとの運用を誤る原因になります。
- 修正案: 完了のページ（28枚目）か61枚目に、確認の後の扱いを書く。例:「サインアウトする前にサーバーを再起動し、『再起動後』の手順で起動タスクから起動したことを確認する。再起動できない場合は、サインアウトせずに作業を続ける」。
- 確認事項: 対象サーバーで、サインアウトしたときに `jenkins.war` と `agent.jar` の `java.exe` が終了するか。
