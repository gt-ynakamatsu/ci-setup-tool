### [重要] エージェント待ちの再実行が、起動中プロセスを閉じる前提を欠く

- 対象箇所: 「再実行の原則」、「主なエラーと対処（エージェント・Token）」の `エージェント ... が 3 分以内にオンラインになりませんでした`
- 問題: スクリプトはこの失敗で、エージェントのウィンドウを閉じ、`start-agent.bat` を別ウィンドウで実行するよう表示する。資料の対処は、ウィンドウで原因を確認し、必要なら `start-agent.bat` を起動して、同じコマンドを再実行する、となっている。再実行の原則は、起動中のエージェントを検出し再利用するため、原因調査で手動起動したウィンドウは閉じなくてよい、としている。
- 理由: `agent.jar` が残っていると、再実行はエージェントを起動し直さず、オンライン待ちだけを繰り返す。API Token 発行はオンライン確認の後なので、この止まり方では `==> 完了` に届かない。資料が「エージェントだけをオンラインにして作業を終えず再実行する」と補っている点は、スクリプトの処理順と一致する。欠けているのは、固着したウィンドウを閉じてから起動し直す操作である。誤った完了判断には直結しないため重大ではなく重要とする。正確性から2点、実用性から1点。
