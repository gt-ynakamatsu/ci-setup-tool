### [重要] 正確性: 環境スキャンの確認数が実装と違う

- 対象箇所: 72ページ「12. エージェント PC を準備する」の手順5
- 問題: 確認する対象を3項目と書いている。
- 理由: `environment_scan.py` の `scan` は Git for Windows、.NET SDK、Java (JRE/JDK)、Jenkins（この PC）の4件を返す。エージェント PC では4件目が未検出になる。正確性から2点減点した。

### [重要] 正確性: ログイン失敗の対処がスクリプトの表示と違う

- 対象箇所: 49ページ、55ページ「ログインできないときの扱い」
- 問題: 49ページは「パスワードを省略して再実行」、55ページは保存済みパスワードでも入れなければ中断し `C:\jenkins` は削除しない、としている。
- 理由: スクリプトの同じエラーは、初回のパスワードで入れない場合は `C:\jenkins` を削除して同じコマンドを再実行するよう表示する。ファイルの値でも入れない場合の回復手順が、スクリプトの表示と逆になる。正確性から2点減点した。
