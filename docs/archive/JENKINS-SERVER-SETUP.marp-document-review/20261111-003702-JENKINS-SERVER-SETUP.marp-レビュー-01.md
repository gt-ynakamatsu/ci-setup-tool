- 問題: 前者は、接続テストに入力が必要かという話と、スクリプトが設定するかという話が1文に混ざっている。原文の「空でも接続テストは成功します」が消えたため、空欄のままでよいのかが分からない。後者の「オンライン到達」は、普通の言い方ではない。
- 理由: 入力欄を空のままにしてよいかで、読み手が迷う。
- 修正案: 「リポジトリ URL、Git 資格情報、Teams Webhook は、接続テストでは空のままでよい」と書く。後者は「エージェントがオンラインになるのを待たずに完了します」にする。
- 確認事項: 空欄のままで接続テストが成功すること（原文の記述で、CISetup では確認していない）。
